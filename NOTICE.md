## Upstream catalogue

The `nschmeller/clash-bases` project is licensed under the MIT Licence. Fortiq packages its catalogue with that licence, retains each entry's attribution, original categories/tags, and official Clash share link, and hotlinks preview images from their original public URLs rather than copying or repackaging the files.

The MIT licence covers the upstream repository. Third-party site terms may still apply to their designs and images; if a source's terms change, its entry in `fortiq/assets/data/catalogue_rights.json` must be set back to `unresolved`, which excludes it from the app without code changes.

## BaseMelon catalogue

The Town Hall 19 and Builder Hall layouts that the MIT-licensed feed does not carry come from BaseMelon, an unofficial fan catalogue with no published reuse grant. Fortiq republishes only the layout title, description, category and the official `link.clashofclans.com` OpenLayout URL, credits BaseMelon and the base creator, and hotlinks the preview from `img.basemelon.com`. The project owner approved including only those TH19/BH records on that basis; base designs and images remain the property of their creators.

## Preview renditions

Grid cards request a smaller rendition of the same public preview where the source host publishes one (for example `-400w.webp`, `sm_crop.jpg`, `?width=400`, imgur `m.jpg`). A few hosts publish a single multi-megabyte original and no rendition — the GitHub-hosted PNGs and the archived oneclash previews — and those are requested through the public weserv.nl image resizer, which returns a resized copy of that same public file. No preview image is bundled with Fortiq, and the full-size preview is still used for the detail view and as an automatic fallback.

## Third-party sources referenced upstream

- `cocbases.com` — inspected page stated “All rights reserved”; images links are followed only where the upstream catalogue supplies them.
- `basemelon.com` — no express Fortiq redistribution grant was found in the inspected requirements/privacy content; see the BaseMelon entry above.
- `blueprintcoc.com` — inspected terms prohibit reproduction/copying without express written permission and prohibit scraping/crawling.
- GitHub seed repositories referenced by upstream — no separate licence or reuse grant was detected during the audit.

Fortiq does not scrape these sites at runtime; it displays the attributed records supplied by the MIT-licensed upstream export and the BaseMelon records that the project owner approved.
