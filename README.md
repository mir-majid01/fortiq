# Fortiq

Fortiq is a Flutter Android/iOS app for discovering Clash of Clans base layouts. It preserves a dark, gold-accented interface with Home, Explore, Collections, base details, filters, and native game-link handoff.

## Repository status

Maintenance status:

- Native Android/iOS Fortiq splash branding and launcher icons are complete.
- Persistent onboarding and favourites are complete.
- Fabricated Community/Profile UI is removed; production has three tabs.
- The real catalogue is live: **5,345 credited bases** (5,194 Home Village TH4–TH19, 151 Builder Base BH4–BH10) are packaged from the MIT-licensed `clash-bases` export and the BaseMelon catalogue, with per-source rights clearance, lossless metadata, official share links, and remote previews.
- Town Hall 19 layouts are included, and the Builder Base section now lists real Builder Hall layouts (never Home Village layouts).
- Grid cards download a lighter preview rendition and decode it at the painted size, so previews load far faster; the full preview is used for details and as a fallback.

The app is unofficial and is not endorsed by or affiliated with Supercell or Clash of Clans.

## Content-rights notice

Fortiq packages the `nschmeller/clash-bases` catalogue, which is published as an MIT-licensed public repository, together with the Town Hall 19 and Builder Hall layouts that only the BaseMelon catalogue carries. Fortiq preserves each entry's attribution, original categories/tags, and official Clash share link, and it hotlinks preview images from their original public URLs instead of copying or repackaging them. Each source is recorded with its own clearance evidence in `fortiq/assets/data/catalogue_rights.json`.

Grid cards request a smaller rendition of the same public preview where the source host publishes one; a few hosts that publish a single multi-megabyte original are requested through the public weserv.nl image resizer, which returns a resized copy of that same public file. No preview image is bundled with the app.

The app is unofficial and does not claim ownership of third-party base designs, preview images, names, descriptions, or share-link payloads. If a source's terms change, flip its entry in `fortiq/assets/data/catalogue_rights.json` back to `unresolved`; the loader excludes that source without code changes.

See [NOTICE.md](NOTICE.md) and [the audit](docs/audit-2026-11-26.md).

## Local development

Requirements: Flutter 3.50.1+, Dart 3.14+, Android Studio/SDK, and Xcode for iOS builds.

```bash
cd fortiq
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter build apk --debug
```

The packaged catalogue is generated by `fortiq/tool/build_catalogue.py` from the upstream export plus `fortiq/tool/fetch_basemelon.py`, and committed as `assets/data/cleared_catalogue.json`. `fortiq/tool/verify_thumbnails.py` checks that every preview rendition still resolves and is smaller than the full preview. Production uses the packaged repository plus private user imports; the sample repository is injected only by local UI/reference tests and is never presented as real production data.

## Releases and APK downloads

Public APKs will be attached to GitHub Releases after the rights review and final verification. The in-app updater will read the latest public release, show version/patch-note/file-size details, download with progress, verify its checksum, and hand the APK to Android's package installer.

Device testers should follow [the device test checklist](docs/device-test-checklist.md).
