# Fortiq

Fortiq is a Flutter app (Android + iOS) for discovering Clash of Clans base
layouts. It ships a dark, gold-accented interface with Home, Explore,
Collections, base details, filters, and native game-link handoff.

The app is unofficial and is not endorsed by or affiliated with Supercell or
Clash of Clans.

## Catalogue

The packaged catalogue is `assets/data/cleared_catalogue.json`, generated by
`tool/build_catalogue.py` from the MIT-licensed `nschmeller/clash-bases` export
plus the BaseMelon records that only it carries (Town Hall 19 and Builder Hall
layouts). It currently holds **5,345 credited bases**:

- 5,194 Home Village layouts (TH4–TH19)
- 151 Builder Base layouts (BH4–BH10)

Every record keeps its source attribution, original categories, and the
official `link.clashofclans.com` OpenLayout URL. Preview images are hotlinked
from their original public URLs and are never bundled with the app; each
record also carries a lighter `thumbnail` rendition so grid cards load fast.
Source clearance evidence lives in `assets/data/catalogue_rights.json`.

## Tools

| Script | Purpose |
|---|---|
| `tool/build_catalogue.py` | Validate and merge the cleared sources into the packaged catalogue. |
| `tool/fetch_basemelon.py` | Fetch the BaseMelon sitemap pages (polite, rate-limited, cached on disk). |
| `tool/verify_thumbnails.py` | Check that every thumbnail rendition resolves and is smaller than the full preview. |
| `tool/probe_catalogue.py` | Print a runtime summary of the packaged catalogue. |
| `tool/compare_goldens.py` | Compare two golden PNGs without third-party dependencies. |

## Running the app

```bash
flutter pub get
flutter run
```

## Quality gates

```bash
flutter analyze --no-fatal-infos
flutter test
```

The golden suite (`test/goldens_test.dart`) is platform-sensitive and is a
Windows-only gate; regenerate it with `flutter test test/goldens_test.dart
--update-goldens` after an intentional visual change.
